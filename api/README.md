# SEOGEO Audit Kit — API

FastAPI service behind [SEOGEO Audit Kit](https://github.com/jaylahoti/seogeo-audit-kit): open-source SEO and GEO
(AI search) audits for programmatic sites, reported per page type. Deployed from this folder with its `Dockerfile`
(`fly.toml` holds the Fly.io settings, `railway.json` the Railway ones); see the main repository for how to run it.
