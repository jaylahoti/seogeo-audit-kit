# SEOGEO Audit Kit — API

FastAPI service behind [SEOGEO Audit Kit](https://github.com/jaylahoti/seogeo-audit-kit): open-source SEO and GEO
(AI search) audits for programmatic sites, reported per page type. The block above configures the Hugging Face
Space it's deployed to; see the main repository for how to run it.
